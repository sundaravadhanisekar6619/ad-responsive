# Real Estate Advertisement Generator V7

Responsive React + TypeScript real-estate advertisement generator.

### V7 preview fitting
- Desktop preview automatically scales the 1080px master poster to fit the available preview column.
- No horizontal clipping of the poster at normal desktop widths.
- Mobile preview uses the full available phone width.
- Export remains a full 1080px master PNG and is not affected by preview scaling.
- Mobile keeps a fixed Download PNG action.

Run:
```bash
npm install
npm run dev
```
